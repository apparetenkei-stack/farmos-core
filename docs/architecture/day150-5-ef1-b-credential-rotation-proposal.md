# Day150.5-B Credential Rotation and Authority-Removal Proposal

Status: `PROPOSAL_ONLY`. This document defines target processes for the ten Windows evidence classes whose **current** `rotation_status` is `NOT_ESTABLISHED`; it does not change that current state and authorizes no rotation, revocation, credential inspection, listener change, or runtime change.

| Class | Owner | Proposed mechanism and dependency | Human approval / order | Validation / rollback | Service or runtime risk |
| --- | --- | --- | --- | --- | --- |
| farmos-core-readonly-token | FarmOS Core credential owner | Scoped replacement through approved server configuration; verified owner and endpoint binding required | Product Owner approves after read-route inventory | server authentication health without value display; revoke new revision and safe-disable | readonly proxy may DEFER |
| farmos-core-daily-brief-token | FarmOS Core credential owner | Scoped replacement through approved server configuration; route classification required | Product Owner approval before proxy window | authenticated route health and redacted audit; revert approved prior revision or disable | daily brief/proposal proxy may DEFER |
| farmos-core-active-projection-token | FarmOS Core credential owner | Scoped replacement through approved server configuration; projection route binding required | Product Owner approval before change | authenticated projection health; revert approved prior revision or disable | active projection unavailable, App operations continue |
| farmos-core-installation-farm-scope | Tenant/installation policy owner | Establish server-owned verified scope binding; EF1-E dependency | Product Owner approval before binding activation | mismatch must fail closed; rollback to no inference/DEFER, never client-selected scope | inference route unavailable until proof |
| farmos-core-workload-private-key | FarmOS workload credential owner | Approved key revision with verification-module deployment plan; workload identity proof required | Product Owner approval and separated implementer/reviewer | signature verification without displaying material; restore approved prior revision or disable verifier | approval verification may be unavailable |
| supabase-migration-authority | Supabase project owner | Human-controlled least-privilege migration principal; actual storage location remains forbidden until approved process | Product Owner approval before any migration work | isolated qualification and access-scope readback; revoke new authority, no automatic migration | migrations deferred; B performs none |

| vercel-deployment-authority | Vercel project owner | Scoped deployment integration replacement; exact target proof required | Product Owner approval before deployment control-plane change | deployment authorization health without value display; revoke new revision or disable integration | deployment unavailable; no production release in B |

| lm-studio-listener-authority | Windows App Runtime Owner | Registered authenticated provider-adapter process with approved listener posture; EF1-H/L and IEG-RUNTIME-READY dependency | Product Owner approval before any listener/authentication change | deny/allow/redaction and authentication fixtures; fail closed to DEFER or approved private path | local inference unavailable; basic farming operations continue |

The four Windows `STORAGE_LOCATION_NOT_VERIFIED` classes are `supabase-migration-authority`, `github-ci-deployment-authority`, `vercel-deployment-authority`, and `slack-app-credentials`. Their physical locations are deliberately not guessed because B forbids Credential Manager/control-plane secret-content access. A finite storage classification completes this inventory requirement; physical storage discovery is not performed here.

The target sequence is: establish owner and bounded scope; obtain Product Owner approval; replace one class in an approved window; validate without displaying a secret; retain only a human-approved rollback revision or safe disablement. No proposal grants Codex, Qwen, Hermes, a browser, or a model production credential visibility or independent egress authority.
